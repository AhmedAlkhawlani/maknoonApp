# مَكْنُون — بوابة المنظومة

موقع فريق **مَكْنُون** (شباب حارة السلام لهندسة وتطوير البرمجيات) — بوابة واحدة للتطبيقات الرسمية وركن التعديلات.

**الرابط:** https://ahmedalkhawlani.github.io/maknoonApp/

---

## البنية

```
index.html                  البوابة (صفحة واحدة، بلا اعتماديات)
assets/css/styles.css       كل الأنماط — لا إطار عمل، لا CDN
assets/js/main.js           تفاعلات خفيفة (~90 سطراً، بلا مكتبات)
assets/fonts/               IBM Plex Sans Arabic — مستضافة محلياً
brand/                      الشعار والأفاتار وبطاقة المشاركة وورقة الهوية
downloads/                  ملفات APK الرسمية
telegram/channel-kit.md     عدة القناة: الوصف والهاشتاقات والقوالب
legacy/                     موقع دفتر مكنون القديم (٢٠٢٦-٠٢) — محفوظ، غير مرتبط
```

## قرارات مقصودة

**لا طلبات خارجية.** لا خطوط من Google، ولا أيقونات من CDN، ولا تحليلات. الصفحة تعمل بلا شبكة بعد التحميل الأول. موقع يعد بعدم التتبّع ثم يستدعي `fonts.googleapis.com` يهدم وعده من أول طلب.

**ادعاءات قابلة للفحص فقط.** «بلا صلاحية إنترنت» مكتوبة عن ميزان وحده، لأنها متحقَّق منها بـ`aapt2`. دفتر مكنون لا يحمل هذا الادعاء لأنه يستخدم Firebase — ولا نكتب ما لا نستطيع إثباته.

**سجل الصلاحيات.** كل بطاقة تطبيق تعرض قائمة صلاحياتها الحقيقية. هذا يفرض علينا الصدق، ويمنح المستخدم أداة تحقّق بدل الثقة العمياء.

## التطوير محلياً

```bash
python3 -m http.server 8899
# ثم افتح http://localhost:8899
```

للمعاينة بلا حركات: `http://localhost:8899/?flat=1`

## النشر

GitHub Pages يخدم من فرع `main` في الجذر. أي دفع إلى `main` يُحدّث الموقع خلال دقيقة.

## الترخيص

الكود ملك فريق مكنون. الشعار والأصول البصرية لا يجوز إعادة استخدامها في مشروع آخر.
